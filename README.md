# StudentHub Portal

A student portal website built with HTML. Provides access to academic information, notices, attendance, results, events, and more.

## Pages Flow

1. **Login** (`login.html`) - Entry page for students to sign in
2. **Register** (`Register.html`) - New student registration
3. **Forgot Password** (`forgot.html`) - Reset forgotten password
4. **Home** (`home.html`) - Dashboard with quick links to all sections
5. **About** (`about.html`) - About the portal
6. **Profile** (`Profile.html`) - Student profile information
7. **Courses** (`Courses.html`) - Available courses list
8. **Timetable** (`Timetable.html`) - Weekly class schedule
9. **Attendance** (`Attendance.html`) - Attendance records
10. **Results** (`Results.html`) - Semester results and grades
11. **Notice** (`Notice.html`) - Latest notices and announcements
12. **Events** (`Events.html`) - Upcoming events
13. **Gallery** (`Gallery.html`) - College gallery
14. **Contact** (`Contact.html`) - Contact information and form

## How to Use

Open `login.html` in any web browser to start.
